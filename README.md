# 🔄 Unit Converter CLI (Python)

A command-line based unit converter developed in Python, rebuilt from an original MATLAB assignment to strengthen programming skills and deepen understanding of core concepts.

---

## 🚀 Features

### 🌡️ Temperature Conversion
- Fahrenheit ↔ Celsius

### ⚖️ Mass Conversion
- Ounces ↔ Grams
- Pounds ↔ Kilograms
- Tons ↔ Tonnes

### 📏 Length Conversion
- Inches ↔ Centimeters
- Feet ↔ Meters
- Miles ↔ Kilometers

---

## 🧠 Highlights

- Menu-driven CLI interface
- Input validation with error handling
- Use of structured functions for each conversion type
- Applied Python `match-case` for clean control flow
- Rebuilt from MATLAB version to improve Python proficiency
